Prompt fotorealistici per la generazione dell'immagine `img4-professione` di ogni MC.
Ogni prompt è ottimizzato per **GPT Image 2 (OpenAI)**, **Midjourney**, **DALL·E 3** e **Flux Pro**.

---

## Istruzioni d'uso

1. Copia il prompt nella sezione `Prompt per GPT Image 2 / DALL·E 3`.
2. Genera in formato **1792×1024** (16:9), qualità **HD**.
3. Salva il file con il nome esatto indicato nella cartella indicata.
4. Prima della pubblicazione passa il file all'**Agente CARBLE-CDD** per validazione [B][R][E].

### Regola su genere e inclusività
I prompt non specificano il genere del professionista — usano termini neutri e mostrano solo
profilo/mani/schiena. Se il generatore produce immagini con genere riconoscibile,
generarne almeno 2 varianti e scegliere quella più equilibrata rispetto al set globale delle 50 MC.
